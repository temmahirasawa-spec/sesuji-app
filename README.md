# 背筋ウィーク | パーソナル夢叶えるタスクマネジメント

🌊 **オーシャンテーマ** × 🚀 **人生を変える習慣システム**

7日間のリファクタリングを通じて、自分を律し、圧倒的な活力を放つあなたへ。

## ✨ 特徴

✅ **localStorage による永続化** - 7日間のタスク完了状況がすべて記憶される  
✅ **セレブレーション** - タスク完了時に✨パーティクルが舞う  
✅ **インスピレーション** - 各日のストーリーと背筋ウィークのテーマ  
✅ **ビジュアルミルストーン** - 7日間の進化の過程を可視化  
✅ **クリーン＆明るい** - オーシャンテーマで希望と爽快感を表現  
✅ **完全レスポンシブ** - スマホ・タブレット・デスクトップ対応

## 🚀 ローカルセットアップ

### 前提条件
- Node.js 16.x 以上
- npm or yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/sesuji-week-app.git
cd sesuji-week-app

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで `http://localhost:3000` を開く。

## 📦 Vercel へのデプロイ

### 方法1: GitHub連携（推奨）

1. **GitHub にリポジトリをプッシュ**
   ```bash
   git add .
   git commit -m "Initial commit: 背筋ウィークアプリ"
   git push origin main
   ```

2. **Vercel にログイン**
   - https://vercel.com にアクセス
   - GitHub アカウントでログイン

3. **新規プロジェクトをインポート**
   - 「New Project」をクリック
   - GitHub リポジトリを選択
   - デフォルト設定のまま「Deploy」をクリック

4. **自動デプロイ完了！**
   - Vercel が自動で Next.js を検出・ビルド
   - 数分後、本番URLが発行される

### 方法2: Vercel CLI を使用

```bash
# Vercel CLI をインストール
npm i -g vercel

# デプロイ
vercel

# プロンプトに従って、プロジェクト名などを入力
```

## 🎯 使い方

### 毎日のルーティン

1. **朝8時に起床**
   - このアプリを開く

2. **当日のタスクをチェック**
   - 完了したら✓をクリック
   - 自動保存される（localStorage）

3. **全体進捗を確認**
   - ヘッダーの進捗バーで成長を実感
   - セレブレーション✨を楽しむ

### データの永続化

- すべてのタスク完了状況は **localStorage** に自動保存
- ブラウザを閉じても、データはそのまま保持
- 複数デバイス間での同期が必要な場合は、クラウドストレージの実装も可能
